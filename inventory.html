Inventory

Set the current stock count for each item. Anything set to 0 shows as "Sold Out" on the shop page immediately.

Internal Tool

Shipping Export

Pirate Ship doesn't connect to this site directly, so this downloads paid orders as spreadsheets. pirate-ship-labels has every Standard Shipping order — one row per package, with its estimated weight and box size — ready to upload at pirateship.com under "Import Spreadsheet" to buy and print labels. Weigh each package before buying its label, since weights are estimates. local-delivery lists Local Delivery orders for your delivery run, with the same columns. Each file downloads only when it has orders. Uses the admin password above. Only new orders — ones not already in a previous export — are included by default.

Internal Tool

Gift Cards

Every gift card sold, newest first. Send now emails a card to its recipient right away (or again, if they can't find it); Resend receipt sends the buyer their copy again. Outstanding balances are money already collected for products not yet sold — keep it in mind at tax and bookkeeping time.

Adjust a Balance

Use this to put money back on a card after refunding an order it paid for (a positive amount, like 25.00), or to take some off (a negative amount, like -10).
