Shipping Export

Pirate Ship doesn't connect to this site directly, so this downloads paid orders as spreadsheets. pirate-ship-labels has every Standard Shipping order — one row per package, with its estimated weight and box size — ready to upload at pirateship.com under "Import Spreadsheet" to buy and print labels. Weigh each package before buying its label, since weights are estimates. local-delivery (only when there are any) lists Local Delivery orders for your delivery run. Uses the admin password above. Only new orders — ones not already in a previous export — are included by default.
